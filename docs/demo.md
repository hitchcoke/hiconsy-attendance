# 시연 순서

초기 시연 시각은 2026-03-12 09:00. `demo:reset`은 서버 종료 후 실행한다.

1. 김근태(`kim`) 로그인 → 출근 → 연차 잔여 2일 확인.
2. 신청에서 3월 13일 연차 1일, 3월 16일 오전 반차, 3월 17일 오후 반차 신청 → 합계 2일 예약, 잔여 0일 확인.
3. 리드 로그인 → 팀 현황에서 김근태의 출근과 날짜별 신청 확인.
4. 리드가 시연 시각을 3월 12일 18:00으로 변경 → 김근태 로그인 → 퇴근 → 근태 상세 8시간 및 이력 확인.
5. 리드가 3월 16일 12:30으로 변경 → 김근태 로그인 → 오전 반차 표시와 출근 확인. 16:30으로 변경 후 퇴근하면 4시간 정상.
6. 리드가 3월 17일 07:30으로 변경 → 김근태 출근. 11:30으로 변경 후 퇴근하면 오후 반차 4시간 정상.

미기록 보정: 다른 팀원으로 출근만 기록한 뒤 리드가 다음 영업일로 변경한다. 해당 팀원으로 로그인하면 출근이 막히고 내 근태에서 이전 퇴근 시각을 입력할 수 있다.

휴일 보상: 초기화 후 금요일 3월 13일 17:00 이전에 토요일 3월 14일 휴일 근무(IP 127.0.0.1, 07:00~20:00)를 신청한다. 해당 시간대에 출퇴근하면 연차에 0.5일이 추가된다. 지급·사용 내역에서 보상과 4월 13일 만료를 확인한다.
