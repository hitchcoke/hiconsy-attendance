## 목표와 제외
직접 재현한 UI 상태 오류를 수정하고 승인 흐름을 포함한 테스트 결과를 Markdown 문서로 공개한다. 운영 정책 추가 변경은 제외한다.

## 선행 및 입력
T17, docs/testing.md 검증 목록, 기존 API 테스트와 scripts/ui-smoke.mjs, 실제 Electron 화면.

## 수정 범위와 사용자 동작

## 완료 조건과 검증
재현된 오류 수정 후 API/빌드/포맷·Electron 회귀 검사, 최소 창 캡처, 테스트 문서와 README 링크, 기능 커밋·병합·GitHub 게시.
