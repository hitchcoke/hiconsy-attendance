# T16 · 로컬 Node 실행 오류 안내

상태: 완료

## 목표와 제외
시스템 Node 21에서 발생한 Vite의 `crypto.hash is not a function` 오류를 해결한다. 전역 Node 설치나 사용자의 셸 설정은 변경하지 않는다.

## 선행 및 입력
T13 실행 기반, scripts/dev.mjs, package.json engines, README 설치 방법.

## 수정 범위와 사용자 동작
- scripts/dev.mjs: 자식 프로세스를 시작하기 전에 Node 24.11 이상(24.x)을 검사하고 실행 명령을 안내한다.
- README: nvm 없이 Node 24 + npm 10.9.4를 사용하는 npx 설치·실행 방법을 추가한다.
- docs/tasks, docs/history: 기능 브랜치·수정·검증·병합 이력을 남긴다.

## 완료 조건과 검증
- 시스템 Node 21.6.0에서 즉시 종료 코드 1과 필요한 버전·복구 명령 출력 확인. 컴파일·서버를 시작하지 않는다.
- `npx --yes --package=node@24 --package=npm@10.9.4 -- npm run dev`로 Node 24.22.2에서 Vite HTTP 200, NestJS 응답, Electron 시작 확인.
- Ctrl+C 후 프로세스 종료와 포트 해제, 포맷 검사 확인.

## 인계
- 변경: 개발 실행 전 버전 검사, 시스템 설정 변경 없이 사용할 수 있는 실행 명령.
- 검증: Node 21 실패 안내·Node 24 정상 시작을 같은 개발 환경에서 직접 확인했다.
- 남은 문제: npx 최초 실행은 인터넷이 필요하며 캐시가 삭제되면 다시 다운로드한다. 이후 정상 Node 24 환경에서는 기존 npm run dev도 사용 가능하다.
- 다음 Task 영향: 개발 실행 명령 변경 시 버전 검사와 README를 함께 유지한다.
