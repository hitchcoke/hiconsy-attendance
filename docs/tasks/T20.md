# T20 · 월간 캘린더 화면과 신청 연결

상태: 완료

## 목표와 제외
월 이동·상태 표시·날짜 상세·신청 폼 연결·리드 팀원 선택을 사용자 화면에 추가한다. 편집·드래그·외부 연동은 제외한다.

## 선행 및 입력
T19, docs/spec.md·contracts.md, shared CalendarMonth, UI App/router·Requests·format.

## 수정 범위와 사용자 동작
Calendar.vue, 탐색 메뉴·라우터, 날짜 전달을 받는 신청 폼. 날짜 클릭/키보드로 상세를 열고 본인 신청 가능 날짜로 신청한 뒤 같은 달로 돌아온다.

## 완료 조건과 검증
타입/빌드와 실제 Electron 월 이동·날짜 상세·신청 결과·리드 선택을 확인한다. 전체 경계·오류·최소 창 회귀는 T21에서 수행한다.
