# T02 · Electron·서버 실행 기반

상태: 완료

## 목표 / 제외
Electron·서버 실행 기반을 구현하고 검증한다. 관리자/정책 편집/승인/PDF/월 정산 제외.

## 입력 / 선행
선행: T01. 공통 docs/spec.md와 docs/contracts.md, 해당 기능의 src/shared/contracts.ts를 먼저 읽는다. 선행 작업과 파일 범위는 docs/tasks/README.md 참조. 전체 대화 이력 대신 이 명세와 선행 Task 완료 기록으로 이어받는다.

## 수정 범위 / 사용자 동작
파일 범위: package.json, electron/, src/server/db.ts·platform.ts·app.ts·main.ts, scripts/dev.mjs.
사용자 동작/목표: 단일 실행, DB 생성·시계·이력 기반.
계약 변경은 docs/contracts.md에 먼저 반영한다. 페이지·컴포넌트 경로는 src/ui/ 기준이다.

## 완료 / 검증
