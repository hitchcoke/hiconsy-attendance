# T02 · Electron·서버 실행 기반

상태: 완료

## 목표 / 제외
Electron·서버 실행 기반을 구현하고 검증한다. 관리자/정책 편집/승인/PDF/월 정산 제외.

## 입력 / 선행
공통 docs/spec.md와 docs/contracts.md, 해당 기능의 src/shared/contracts.ts를 먼저 읽는다. 선행 작업과 파일 범위는 docs/tasks/README.md 참조. 전체 대화 이력 대신 이 명세와 선행 Task 완료 기록으로 이어받는다.

## 수정 범위 / 사용자 동작
README의 작업 소유 범위를 지키고 계약 변경은 docs/contracts.md에 먼저 반영한다.

## 완료 / 검증
실제 API 연결, 정상/오류/빈 상태, 관련 경계값 테스트를 확인한다. 자세한 증거는 완료 후 아래 기록.

## 인계
- 변경: Electron/Vue/NestJS 기반, SQLite 마이그레이션/시드, 규칙/시계/인증 기본 서비스, 개발 실행 스크립트
- 검증: npm run build 및 npm run db:init 성공
- 남은 문제: 실제 Electron 화면 기능/패키징 검증은 T03/T13에서 수행
