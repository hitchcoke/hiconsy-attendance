# T15 · 연차 통합 및 오전·오후 반차

상태: 완료

## 목표 / 제외
별도 OFF 사용·잔여 UI를 제거하고 휴일 근무 보상도 연차에 0.5일로 합산한다. 연차 1일, 오전 반차 0.5일, 오후 반차 0.5일을 선택한다. 정책 편집·신청 취소는 추가하지 않는다.

## 입력 / 선행
T04~T12, docs/spec.md, docs/contracts.md. 사용자 최신 지시가 초기 OFF 분리 계획보다 우선한다.

## 수정 범위 / 사용자 동작
DB 마이그레이션, 원장·신청·근태 규칙, 잔여 카드, 휴가 신청의 기간 선택, 오늘·팀 표시.
- 원장 정수 1단위=0.5일. 월 적립 +2단위, 휴일 보상 +1단위(30일 유효).
- 연차 사용 -2단위, 오전/오후 반차 -1단위. 사용일까지 유효한 만료 임박 적립분부터 차감.
- 오전 반차: 12:30부터 출근, 12:30 초과 지각, 4시간 근무 기준.
- 오후 반차: 11:30부터 퇴근 등록, 근무 인정은 11:30까지, 4시간 기준(07:30~11:30이면 정상). 늦게 퇴근 등록해도 오후 시간이 더해지지 않는다.
- 기존 OFF 개발 데이터는 오후 반차로 이관하고 기존 계산 결과는 보존한다.

## 완료 / 검증
두 반차 각각의 0.5일 차감·점심 경계·지각/조퇴·직접 입력·만료 순서·동시 차감·기존 DB 마이그레이션을 검증한다. Electron에서 오전/오후 선택과 표시를 확인한다.

- 검증: API/규칙/마이그레이션 테스트 24개 통과, Electron 오전·오후 선택 및 0.5일 차감 시나리오 통과, 폼 캡처 검토
