# T13 · Electron 패키징·실행 검증

상태: 완료

## 목표와 제외
Forge로 macOS 앱을 만들고 별도 NestJS 서버에 연결한다. Windows/Linux 실행, 코드 서명·공증·자동 업데이트는 제외한다.

## 선행 및 입력
T12, T15 완료 기록, docs/spec.md·contracts.md, electron/main.cjs, forge.config.cjs, scripts/ui-smoke.mjs.

## 수정 범위와 사용자 동작
- scripts/dev.mjs: 서버·Vite·Electron 동시 실행과 포트 충돌 안내, 함께 종료.
- vite.config.mts, .env.example: 빌드 시 서버 주소 및 CSP 반영.
- package.json·잠금 파일: Forge가 요구하는 npm 최소 버전 10.9 명시.
- scripts/ui-smoke.mjs: 배포 실행 파일 지원, 실제 서버 종료·재시작과 앱 재실행 검증.
- 사용자는 서버를 시작하고 앱을 열어 로그인·출퇴근·신청·팀 확인을 수행한다. 연결 실패 시 재연결하고 서버 재시작 후 다시 로그인한다.

## 완료 조건과 검증
- `npm run make` 성공, 생성된 macOS arm64 앱에서 UI 시나리오 9개 묶음 통과, 렌더러 오류 0건.
- 동일 SQLite DB로 서버 재시작 시 근태·반차 예약·잔여·시연 시각 유지.
- 앱 재실행 후 상태 복원, 최소 창 가로 넘침 없음.
- `npm run dev` 실행·종료 및 3000/5173 포트 해제 확인.
