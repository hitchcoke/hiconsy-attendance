# T21 · 캘린더 회귀 검증과 제출 문서

상태: 완료

## 목표와 제외
월간 캘린더의 사용자 흐름·권한·경계·연결 오류·최소 창을 검증하고 재현 방법과 실제 결과를 문서화한다. 달력 편집·드래그·외부 연동은 제외한다.

## 선행 및 입력
T19/T20, docs/spec.md·contracts.md·testing.md, calendar.ts·Calendar.vue·Requests.vue, 기존 UI 회귀.

## 수정 범위와 사용자 동작
scripts/calendar-smoke.mjs, package.json, 발견 문제의 UI, README·테스트 문서·화면 증거·Task/Git 기록.

## 완료 조건과 검증
서버 테스트·UI 타입/빌드·포맷 통과. 실제 Electron에서 월 이동, 신청→승인/반려→달력 복귀, 팀원 선택, 작은 창·키보드·응답 순서 역전·연결 복구를 확인한다. 사용자 DB·실행 중 서버는 건드리지 않는다.

## 인계
- 변경: 임시 포트·DB·빌드로 분리한 캘린더 Electron 회귀 스크립트, 긴 상세에서도 보이는 고정 신청 영역, README·시연·테스트 결과·화면 증거를 추가했다.
- 검증: 서버 38/38, 기존 Electron 16개 묶음, 캘린더 10개 묶음 통과. 렌더러 오류 0. 타입·빌드·포맷·macOS Forge ZIP 생성 통과. 실제 화면과 최소 창 캡처 확인. 결과는 docs/testing.md와 docs/test-results/calendar.json.
- 남은 문제: 2026년만 지원. Windows/Linux 및 이번 ZIP의 패키지 실행 경로는 미검증이며 프로덕션 렌더러를 실제 macOS Electron에서 검증했다. 기존 T13 패키지 실행 검증과 구분한다.
- 다음 Task 영향: 달력 범위 확장 시 공통 계약부터 갱신한다.
