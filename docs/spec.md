# 제품 명세

Electron + Vue 사용자 앱, NestJS 별도 서버, SQLite. 팀원(MEMBER)은 본인 데이터만, 리드(LEAD)는 본인 기능과 팀 현황을 사용한다. 관리자·정책 편집·승인·PDF·월 정산·신청 취소는 제외한다.

## 화면
로그인 → 오늘(/today), 신청(/requests), 내 근태(/history), 리드의 팀 현황(/team). 공통 시연 패널은 시연 모드에서 표시하고 리드만 시각을 변경한다. 밝은 배경, 왼쪽 탐색, 큰 출퇴근 버튼과 상태·잔여 카드. 서버 연결 실패/빈 결과/로딩/오류/권한 제한을 표현한다.

## 고정 규칙
- Asia/Seoul. 서버 시각으로 출근 07:00부터, 10:00:00 초과 지각, 퇴근 16:00부터.
- 근무 구간에 11:30~12:30 전체가 포함되면 1시간 차감. 순 근무시간 8시간 미만 조퇴.
- 연차와 휴일 보상을 통합한다. 연차 1일, 오전/오후 반차 각 0.5일 차감.
- 오전 반차는 12:30부터 출근, 12:30 초과 지각, 4시간 기준. 오후 반차는 11:30부터 퇴근 등록, 근무시간은 11:30까지만 인정하며 4시간 기준(07:30~11:30).
- 재택 월 2회, 사용일의 월 기준, 이월 없음.
- 연차 입사 한 달 후부터 매월 1일분. 없는 날짜는 해당 월말, 다음 달은 원래 입사일 기준. 연차 만료 없음. 지급된 잔여만 사용 예약.
- 주말/공휴일 근무는 확정 신청의 IP·시간대 안에서 출퇴근. 퇴근 완료 시 근무일당 연차 0.5일, 실제 퇴근일+30일까지 사용 가능. 직접 입력도 동일하고 중복 지급 금지.
- 모든 신청은 대상일 전 영업일 17:00까지(정각 포함). 신청 즉시 확정. 하루 한 종류. 연차/반차/재택은 영업일, 휴일 근무는 비영업일만 신청.
- 통합 연차에서 사용일까지 유효한 만료 임박 적립분부터 예약 차감.
- 하루 한 근태, 야간 근무 제외. 미기록 퇴근은 본인 기록에 대해 해당 일의 출근 이후·현재 이전 입력. 일반 퇴근 최소 시각과 휴일 신청 시간대도 적용. 과거 접속 IP는 재현 불가하므로 현재 접속 권한 확인과 직접 입력 표시/이력으로 보완.
- 연구실은 상시 접속 허용. 그 외 접속은 본인 신청 IP/시간대 필요. 재택·휴일 출퇴근은 연구실 IP에서도 신청 IP/시간대를 추가 검사.
- 기존 기록은 다시 계산하지 않는다. 신청과 차감·성공 이력은 원자적 저장. 중복 출퇴근/지급 방지는 DB 제약과 직렬화 트랜잭션으로 보장.

## FR 대응
SYS-01 접속 및 근태 IP 검사; SYS-02 로그인/역할; ATT-01~04 출퇴근/보정/휴일; REQ-01 신청; BAL-01 잔여; DSH-01 오늘/팀/미기록; LOG-01 서버 API 조회·변경·실패 이력. 포인터 이동 등 업무 요청이 없는 UI 동작은 이력 대상 아님.

## 시연
기본 2026-03-12 09:00 KST, 시연 시각은 고정되어 있고 리드가 앞으로 변경한다. 과거로 돌아가려면 서버를 종료하고 demo:reset. 실제 실행은 실제 서버 시각, 인증 만료는 언제나 실제 시각.
