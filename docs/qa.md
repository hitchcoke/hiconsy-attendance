# 검증 계획 및 결과

## 화면 검증 목록
- 로그인: 4개 샘플 계정 버튼, 비밀번호 표시, 잘못된 비밀번호, 연결 오류/재시도, 로그아웃.
- 공통: 사용자/리드 메뉴 차이, 직접 경로 접근 제한, 실제 초기 창과 최소 크기, 키보드/포커스, 가로 넘침.
- 오늘: 출근 전/근무 중/퇴근, 제한 사유, 새로고침, 퇴근 확인 취소·확정, 일정 이동, 잔여 상세.
- 신청: 연차·반차(오전/오후)·재택·휴일 근무 전환, 날짜 마감 안내, IP/시간 입력, 잔여 부족, 중복 신청, 성공 목록, 닫기.
- 근태: 기간 조회, 빈 결과, 상세 이력, 미기록 보정의 오류·성공.
- 리드: 날짜 조회, 팀 보드/신청/미기록 탭, 팀원 상세, 본인 화면과의 일치.
- 시연: 리드만 편집, 닫기, 빠른 시간 선택, 직접 입력, 과거 거절, 변경 후 화면 갱신.
- 장애 탐색: 서버 연결 끊김/복구, 세션 복원 실패, 과거 날짜 신청, 보정 후 다음 출근.

## 검증 증거
자동 테스트: src/server/tests. 화면 검증: 실제 Electron 창을 Playwright로 조작하며 artifacts/에 캡처. 최종 결과는 아래 T12/T13/T15 기록을 참고한다.

## T12 결과
- 실제 Electron에서 로그인 오류, 출근, 연차 신청/차감, 잔여 원장, 리드 팀 현황/상세/탭, 시각 변경, 퇴근 취소/확정, 미기록 보정을 조작해 확인.
- 재현 가능한 `npm run test:ui` 추가: 서버 연결 실패/재연결과 최소 860×680 창 가로 넘침 검사 포함.
- 화면 캡처: artifacts/ui/*.png, 자동 결과: artifacts/ui/report.json. 렌더러 오류 0건.
- 오류 후 재조회가 오류 문구를 지우던 동작, 세션 만료 복원, 오프라인 로그아웃, 화면 전환 스크롤을 수정.
- 사용자 요청에 따라 감성 문구/장식 설명 제거. 실사용에 필요한 규칙·오류 안내만 유지.
- 2026 공휴일 초기 월력요항에 후속 지정된 노동절/제헌절 반영: [인사혁신처 보도자료](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?boardId=bbs_0000000000000029&cntId=4250&mode=view), [주일본 대사관 제헌절 공지](https://jp.mofa.go.kr/jp-ko/brd/m_1083/view.do?seq=1343728).

## T15 결과
- 서버 규칙·API·마이그레이션 자동 테스트 24개 통과.
- 연차 1일·오전 0.5일·오후 0.5일의 공통 잔여와 동시 신청 초과 차감 방지 확인.
- 12:30 오전 반차 출근·11:30 오후 반차 퇴근 경계, 4시간 근무·지각·조퇴·직접 입력 확인.
- 이전 OFF DB의 신청·원장·참조 관계 이관과 저장된 근무시간 보존 확인.

## T13 결과
- macOS arm64, Node 24.22.2, npm 11.21.1, Electron 45.2.1에서 `npm run make` 성공.
- 생성된 `.app` 실행 파일로 UI 시나리오 9개 묶음 통과, 렌더러 오류 0건. `artifacts/packaged/report.json` 및 화면 캡처 생성.
- 실제 NestJS 서버 종료 시 연결 오류 표시 → 동일 DB로 서버 재시작 → 재로그인 후 퇴근·잔여·시연 시각 보존 확인.
- 실제 앱 종료·재실행 후 오늘의 퇴근 상태 복원 확인.
- 최소 860×680 창에서 신청 화면 가로 넘침 없음. 폼·표·상태 화면 캡처 육안 확인.
- `npm run dev`로 서버·Vite·Electron 동시 시작, 종료 후 3000/5173 포트 해제 확인.
- 패키지: `out/make/zip/darwin/arm64/Hiconsy Attendance-darwin-arm64-1.0.0.zip`. Windows/Linux·코드 서명·공증은 검증 범위 밖.
